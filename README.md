### Featured Build: AI Fitness Platform

**Repository**: [`saketh752/AI_Fitness_Platform`](https://github.com/saketh752/AI_Fitness_Platform)  
**Architecture**: Polyglot Microservices (`Full-Stack · AI`)

A full-stack fitness engineering platform combining real-time computer vision kinematic tracking, autonomous AI coaching, and enterprise persistence.

#### System Architecture:
- **Mobile Client**: Cross-platform Flutter / Dart application for real-time video capture, camera feed ingestion, and interactive user flows.
- **Core Business Backend**: Java 21 and Spring Boot enterprise core handling authentication, workout scheduling, profile state, and API routing.
- **Computer Vision Service**: Python / FastAPI microservice leveraging Google MediaPipe for landmark coordinate extraction, rep kinematics, and biomechanical posture analysis.
- **AI Coaching Engine**: Python / FastAPI microservice integrated with Groq Cloud (Llama 3) for contextual form feedback and automated workout summaries.
- **Persistence & Migration**: MySQL 8.0 with versioned Flyway database migrations and relational data integrity.
- **Infrastructure**: Containerized with Docker Compose multi-service network definitions and environment configuration.
